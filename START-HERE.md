# SLIM PICKINGS starter — what to do with this folder

1. Create the repo (default: majorfrazer/slim-pickings) and copy everything in this folder to its root.
   CLAUDE.md and AGENTS.md stay at the root; docs/ stays as docs/.
2. Settle the six Open Decisions at the end of docs/build-brief.md (or say "defaults").
3. Open the repo in VS Code. Paste docs/kickoff-claude-code.md into Claude Code. That starts Phase 0.
4. When Claude Code posts its phase report, paste docs/kickoff-codex.md into Codex. That runs the Phase 0 check.
5. Read both reports, click the preview, merge or send it around again. Then Phase 1.

docs/press-kit.md is the canonical copy (as the doc stood on 13 Oct 2026, restores included).
If the Press Kit tab changes again, re-export it over this file before the next phase.
